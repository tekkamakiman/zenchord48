全コード進行サイト（仮）

番号 N を入れると、その N に対応する 4小節のコード進行 が鳴ります。N と進行は1対1対応で、変換ルールに好みは入りません。全俳句サイトの、コード版です。

1小節＝和音1つ。12鍵（ド〜シ）のオン／オフで 12ビット＝4,096通り、4小節で 48ビット＝281,474,976,710,656通り（約281兆）。1小節1秒で全部聴くと約3,600万年かかります。

マス目がそのまま N の2進数です。各小節は上（シ）から下（ド）へ12鍵。マスをタップすると音が1つ増えたり減ったりします。小節下の −／＋ は金庫のダイヤル式に、その小節の値（0〜4,095）を1ずつ回します（数値の上でホイールを回しても変わります）。

プリセット

有名な進行も、結局はどれか1つの N です。王道進行は N = 37,488,698,130,961 の位置にあります。

仕組み

変換ルール（これだけ）

  • 音は12個：ド=0、ド♯=1、レ=2、……、シ=11 と番号を振る。
  • 1小節の値は、その小節で鳴らす音の 2音番号 の合計。たとえばド・ミ・ソ（C）は 20+24+27 = 145。
  • N は4小節を並べたもの：N = 第1小節×40963 + 第2小節×40962 + 第3小節×4096 + 第4小節。
  • 鳴らすときは、オンの音をド4〜シ4の1オクターブで同時に鳴らすだけ。ベース音の追加や転回などの「味付け」はしない。
  • 楽譜表示はしない。ド♯／レ♭の書き分けで恣意性が入るため。

コード名について

名前がある和音（C、Dm、G7 など）だけ名前を表示します。判定は根音を12通りすべて試し、音の並びが既知の型に一致するかで決めます。C6 と Am7 のように複数の名前が成り立つ和音は、両方を併記します。どの型にも当てはまらない和音は「名前なし」で、それも含めて全4,096通りが対等です。

数と先例

進行の総数281,474,976,710,656 通り（40964）
